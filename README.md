# AeroGo

AeroGo is a modern full-stack web application designed to simulate a real-world flight ticket booking system. The project demonstrates how to build a **scalable, performant, and production-ready web platform** using modern JavaScript tehcnologies and best practices.

The application is built with **Next.js** as the core framework, leveraging, its server-side rendering (SSR) and modern routing capabilities to deliver high performance, excellent SEO, and maintainable architecture.
AeroGo integrates authentication, database management, file storage, and payment processing to reflect real-world product requirements commonly found airline and travel platforms.

## Tech Stack

### Frontend:

- Next.js (App Router)

- React

- TypeScript

- Tailwind CSS

- shadcn/ui (customized components)

### Backend & Data

- Prisma ORM

- PostgreSQL

- Server Actions & API Routes

- Lucia Authentication

### Storage & Infrastructure

- Supabase Storage (file uploads)

- Vercel (deployment & hosting)
